# Portfolio Demo Script

Target length: **45–60 seconds**

## Before recording

Open three things:
1. `input/support_tickets.xlsx`
2. A terminal in the project folder
3. `output/weekly_support_report.xlsx`

Keep the GitHub repository open in another tab if you want to finish on it.

## Recording flow

### 0–8 seconds: Show the raw input

Open `input/support_tickets.xlsx`.

Say:

> "This project automates weekly support reporting from raw Excel or CSV ticket data."

Briefly scroll through the ticket columns so the viewer can see the input is structured business data.

### 8–18 seconds: Run the automation

Switch to the terminal and run:

```bash
python report_generator.py input/support_tickets.csv output/weekly_support_report.xlsx
```

Say:

> "The Python script validates and processes the data, calculates the KPIs, and automatically generates the management report."

Show the successful `Report created` message.

### 18–40 seconds: Show the dashboard

Open `output/weekly_support_report.xlsx` and select the **Dashboard** sheet.

Say:

> "The output includes headline KPIs such as ticket volume, closed tickets, average resolution time, SLA compliance, and ticket priority distribution."

Pause briefly on the dashboard.

### 40–52 seconds: Show deeper analysis

Click **Agent Performance** and then **Category Analysis**.

Say:

> "Managers can also compare agent workload and performance, and analyze ticket volume and SLA results by category."

### 52–60 seconds: Finish

Say:

> "The same reporting workflow can be adapted to customer service, maintenance, sales, project tracking, or other recurring Excel reporting processes."

Optionally finish on the GitHub repository page.

## Recording tips

- Record at 1080p if possible.
- Keep the mouse movements slow and deliberate.
- Do not show personal notifications, passwords, browser bookmarks, or confidential work information.
- No webcam is required.
- No advanced editing is required.
- A clean screen recording with clear narration is enough for the portfolio.
